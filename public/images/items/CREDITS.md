# 품목 이미지 출처

시세 카드·상세 화면의 품목 사진(`*.webp`)은 모두 [Pexels](https://www.pexels.com)에서 내려받은 사진이다.

- 라이선스: [Pexels License](https://www.pexels.com/license/). 개인·상업 용도로 무료 사용과 수정이 가능하고, 출처 표기는 필수가 아니다.
- 가공: 정사각형으로 자르고 480×480 webp로 변환(EXIF 메타데이터 제거). 원본 색은 바꾸지 않았다.
- 개별 사진 페이지 주소는 기록하지 못했다. 아래는 내려받을 때 사용한 검색 페이지다.

| 파일 | 품목 | 검색 페이지 |
|---|---|---|
| `green-onion.webp` | 대파 | https://www.pexels.com/search/green%20onion/ |
| `onion.webp` | 양파 | https://www.pexels.com/search/onion/ |
| `peeled-garlic.webp` | 깐마늘 | https://www.pexels.com/search/peeled%20garlic/ |
| `napa-cabbage.webp` | 배추 | https://www.pexels.com/search/napa%20cabbage/ |
| `radish.webp` | 무 | https://www.pexels.com/search/daikon/ |

새 품목 사진을 추가할 때는 같은 기준(무료 라이선스, 정사각형 480×480 webp)으로 넣고 `lib/prices/item-images.ts`에 이름을 연결한다.
